Clyde privacy policy

Last updated 30 September 2026.

Clyde is a personal tool used only by its owner, Alex Makelberge. Only Alex's own Google accounts are connected to it.

What it accesses

  • Gmail (read-only): to find events, bookings and deadlines in Alex's own email.
  • Google Calendar: to create and update events in calendars owned by Alex's account, and to reply to invitations sent to it.

How data is used

  • Data is used only to keep Alex's calendar up to date and to send Alex reminders.
  • Email content may be sent to Anthropic's Claude API to extract event details. It is not used to train models.
  • Data is stored on a private server controlled by Alex. It is never sold or shared with anyone else.
  • Calendars are shared with other people only when Alex chooses to.

Google API Services

Clyde's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.
